JRE включва JVM за изпълнение на bytecode, който е създаден при компилацията на source кода и библиотеки .jar, които са вградени.
JVM използва JIT, за често използвани функции за всяка bytecode инструкция, генерира собствен машинен код, който пропуска C слоя и изпълнява директно логиката на фунцкията.

Когато се стартира java MyApp, JVM не търси всички JAR файлове безразборно, а има строг ред наречен ***Delegation Model***.
1️⃣ Bootstrap Class Loader  →  зарежда базовите класове (java.lang, java.util, java.io…)
     ↓
2️⃣ Platform Class Loader   →  зарежда системни и разширителни библиотеки (java.sql, javafx и др.)
     ↓
3️⃣ Application Class Loader → зарежда всичко от classpath (твоите и външните JAR-ове)
