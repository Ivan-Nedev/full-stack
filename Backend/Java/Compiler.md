Компилаторът в java, javac , компилира source кода, на път на файловата система на записващото устройство, към bytecode, .class файл. Bytecode-а е универсален и от там идва WORA - "Write once, run everywhere".
Bytecode-а се изпълнява от виртуалната машина на Java - JVM съдържаща се в JRE. Представлява цикъл на ниско ниво език C и изпълнява инструкции матчващи bytecode - c функция и изпълня
